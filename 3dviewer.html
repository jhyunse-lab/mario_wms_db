📦 WMS 3D 대시보드 사용자 매뉴얼

본 매뉴얼은 WMS 3D 스마트 창고 대시보드의 모든 기능과 효율적인 조작 방법을 안내합니다.

🎮 1. 3D 화면 기본 조작법 (카메라 컨트롤)

동작 조작 방법 설명
회전 (Rotate) 마우스 좌클릭 + 드래그 3D 창고를 다각도에서 입체적으로 회전하여 봅니다.
이동 (Pan) 마우스 휠(중간 버튼) 클릭 + 드래그 화면 시점을 상/하/좌/우로 평행 이동합니다.
확대/축소 (Zoom) 마우스 휠 스크롤 화면을 확대하거나 축소합니다.
선반/품목 모드 전환 마우스 우클릭 (Context Menu) 우클릭 메뉴를 열어 '선반 선택 모드' 또는 '품목 선택 모드'를 자율 선택/전환합니다.
객체 선택 (Select) 3D 박스 또는 선반 좌클릭 선택된 박스/선반에 초록색 강조 테두리가 표시되며 우측 카드가 업데이트됩니다.
선택 해제 (Clear) 3D 바닥(빈 공간) 더블클릭 선택 상태가 모두 해제됩니다.

🎛️ 2. 오른쪽 컨트롤 패널 활용법

2.1. 분석 모드 (Color Modes)

우측 상단의 [분석 모드] 드롭다운에서 원하는 시각화 기준을 선택합니다.

  • 🏢 제조사별: 제조사(Maker)에 따라 3D 박스 색상을 다채롭게 구분합니다.
  • 🤝 거래처별: 거래처/화주(Partner) 단위로 색상을 구별합니다.
  • 🎖️ 출고등급: 마지막 출고정보(최종출고일자) 기준으로 4단계 색상이 적용됩니다.
    🟢 A등급: 2026년 이후 출고 이력 🟡 B등급: 2025년 출고 이력 🔵 C등급: 2024년 이전 출고 이력 🔴 D등급: 출고 이력 없음
  • 🚨 특이사항: 이슈/메모가 등록된 품목만 고유 색상으로 구별 강조하고, 메모가 없는 품목은 회색으로 보입니다.

2.2. 선반 시각화 토글 & 경신/GNN 영역 하이라이트

  • ⬛ 선반/기둥 (ON/OFF 스위치):
    OFF로 변경하면 철제 선반과 기둥 프레임이 숨겨지고 재고 박스만 공중에 선명하게 노출되어 내부 시인성이 극대화됩니다.
  • 🟧 경신 / 🟦 GNN 체크박스:
    - 경신 체크 시: B01, A01(25번~), A02(25번~) 영역이 주황색 바닥/프레임으로 강조됩니다.
    - GNN 체크 시: C02(09~14번) 영역이 파란색 바닥/프레임으로 강조됩니다.

2.3. 선택된 객체 카드 & 메모/이슈 기록 기능

3D 박스나 하단 테이블 행을 선택하면 우측 선택된 객체 카드에 상세 정보가 표기됩니다.

  • 표시 정보: 종류, 로케이션, 품목명[품목코드], DC, 출고등급, 제조사명, 거래처명, 수량
  • 📝 [이슈/메모 기록] 버튼:
    - 버튼을 클릭하면 자유롭게 드래그(Drag) 이동이 가능한 메모 창이 열립니다.
    - 상단 탭: 품목별, 제조사별, 거래처별 메모를 독립적으로 작성하고 이전 기록을 조회할 수 있습니다.
    - 📸 이미지 첨부: 스크린샷 캡처 이미지를 메모 창에 Ctrl+V로 직접 붙여넣기 하거나 파일 첨부가 가능합니다.

📊 3. 데이터 엑셀 연동 & 테이블 활용법

3.1. 현재고 엑셀 업로드

  • [① 현재고 엑셀] 버튼을 눌러 재고현황상세 .xlsx / .xls 엑셀 파일을 업로드합니다.

3.2. 재고 인벤토리 테이블 조작

  • 🔍 통합 검색창: 로케이션, 품목명, 품목코드, 제조사, 거래처, DC 입력 시 실시간으로 테이블과 3D 뷰어가 동시에 필터링됩니다.
  • ↔️ 열 너비 마우스 드래그 조절: 테이블 헤더(로케이션, 품목명, 제조사명, 거래처명, DC, 수량)의 경계선을 클릭 후 마우스로 좌우 드래그하여 원하는 넓이로 조절합니다.
  • 🔃 더블클릭 정렬: 테이블 헤더 글씨를 더블클릭하면 해당 열 기준으로 오름차순(▲) / 내림차순(▼) 정렬됩니다.
  • 📥 [엑셀로 내보내기]: 현재 화면 및 필터에 조회된 인벤토리 데이터를 .xlsx 엑셀 파일로 바로 다운로드합니다.
💡 Tip: 3D 화면이 어두울 경우 우측 투명도 슬라이더나 선반 ON/OFF 스위치를 조작해 보세요!
